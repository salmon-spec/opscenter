# OpenCode 能力覆盖与验收

2026-10-23，模块 0.2.0 / 原生 OpenCode 1.19.3。执行、模型循环、工具、权限、任务状态、MCP 和快照由 OpenCode 提供；工作台界面、JWT 网关、目录选择、审计及终端桥接由本项目集成开发。

| 能力 | 模块入口 | 本次验证 |
| --- | --- | --- |
| 完整官方交互 | 顶部「原生 OpenCode」，同一服务、目录和任务的官方 TUI | 真实 PTY attach、命令面板 |
| Build / Plan / 自定义 Agent | 输入框 Agent 选择、扩展设置 | Build 真实模型执行；自定义 Agent 发现与删除 |
| 原生模型提供方、推理选项 | 模型连接与输入框 | 原生目录；免费 DeepSeek 模型真实调用 |
| 任务管理 | 新建、搜索、重命名、归档、分支、撤销/恢复、压缩、导出、历史 | 生命周期；真实任务快照撤销/恢复 |
| 文件、附件、差异 | 文件/变更侧栏与「＋」 | 读写、路径边界、文本附件；原生 Git 初始化 |
| 命令执行 | 模型工具与真实 Bash 终端 | 模型编写 Python、运行 5 项测试；PTY 输入/输出/缩放/中断 |
| MCP 与自定义命令 | 设置与扩展、输入框 /命令 | 本地 stdio MCP 回显、原生命令、附件、连续任务联合实测 |
| 规则与技能 | 工作区 AGENTS.md、.opencode/skills | 技能被原生发现；规则/技能执行仍遵循原生引擎 |
| 工具审批、任务权限、提问、停止 | 输入框「需要询问 / 完全控制 · 容器」、对话内原生请求 | 真实自动执行、默认询问隔离、切回询问、单次批准；Plan命令拒绝规则回归 |
| 清单、子任务、Token、费用、思考、Markdown | 对话与详情侧栏 | 原生数据读取、界面及测试；未执行真实嵌套子 Agent |
| npm 插件、OAuth、MCP 认证、LSP、格式化及其他高级操作 | 原生配置、官方 TUI / CLI | 保留原生入口；需实际插件、账户、语言服务或回调条件，未逐项端到端验收 |

文本附件使用原生 file:// 文件引用，内容读取、截断及图像准备交给 OpenCode；图片/PDF 支持取决于模型。撤销文件需要原生可用 Git 快照；初始化 Git 仅将当前注册工作区加入持久信任列表，不提交或推送。

默认关闭分享和自动升级。执行容器没有生产 SSH 凭据、Kubeconfig、Docker socket 或 ServiceAccount Token；接入真实运维目标仍需为任务配置访问。工作区是同一管理员的目录划分，不是多租户隔离。

本次免费模型经 OpenCode 提供，不等于 DeepSeek 官方 API Key 直连通过。Go / DeepSeek 官方直连、外部 OAuth、远端 MCP 与具体插件尚待有效配置。Chrome 自动化生产沙箱空白问题仍存在；内置浏览器生产验收通过。
