## 发布规则

1. 每次代码变更都必须递增版本号，并同步后端、前端、部署镜像和验收脚本。
2. 功能新增使用次版本号，例如 `v5.3.0`。
3. 兼容性缺陷修复使用修订号，例如 `v5.3.1`。
4. 发布时按版本先后顺序补标签，不跳号覆盖；补标前先确认对应代码已经合并并完成验收。

## 本轮发布动作

- 将累计代码提交为 v5.3.1 发布状态。
