# OpsCenter 5.5.23 — 密码管理入口

新增密码管理模块 `password-manager` 0.1.0：原生工作台页面展示独立 Vaultwarden 密码库入口、HTTPS 连接状态、服务器地址复制、浏览器扩展和手机客户端配置说明。模块目录支持显示/隐藏和真实健康检查。

健康探测使用服务端配置的固定 HTTPS 根地址，验证证书链与主机名，禁用重定向及环境代理，只读取公开配置和登录页面。探测响应不包含配置原文、账号、密码条目或原始错误。工作台认证信息不传入密码库，密码库保留自己的登录、解锁与客户端加密。

## 部署配置

设置 `VAULTWARDEN_URL=https://10.66.66.13:8443`；私有 CA 环境设置 `VAULTWARDEN_CA_FILE=/etc/opscenter/vaultwarden/ca.crt`。创建公有证书 ConfigMap 后，将 `deploy/k8s/opscenter-password-manager.patch.yaml` 作为 backend 的 strategic merge patch 应用。Caddy 使用本版本配置，为 `/modules/password-manager/{status,health,start,stop}` 提供固定网关。

```sh
kubectl -n opscenter create configmap opscenter-password-manager-ca-20261025 \
  --from-file=ca.crt=frontend-vite/public/certificates/opscenter-internal-ca.crt \
  --dry-run=client -o yaml | kubectl apply -f -
kubectl -n opscenter patch deployment backend --type=strategic \
  --patch-file deploy/k8s/opscenter-password-manager.patch.yaml
```

密码库使用已有 Vaultwarden 数据卷；WireGuard IP 入口以家庭服务 CA 签发包含该 IP 的证书。新设备需信任对应 CA。公有 CA 证书随前端提供下载，私钥仅保留在服务端受限目录。既有自动备份策略保持当前配置。
