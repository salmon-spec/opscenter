# OpsCenter 5.5.33

新增主机 WireGuard 自动发现：Agent 健康检查约每三分钟读取接口地址并同步到主机台账，保持原管理通道选择；发现失败保留上次地址。主机详情提供 WireGuard 接口、地址、Peer 与最近握手的只读检测页。

automation 0.4.0 支持页面运行参数。通用模板接受有界标量 JSON extra vars；WireGuard 安装模板提供目标主机、Hub、接口、地址池及 Endpoint 表单。默认检查模式只读预览；正式执行使用已保存的 SSH 凭据，目标本机生成私钥，自动排除 Hub 实时与持久 Peer 及台账占用地址。分配使用数据库会话锁，Hub 写入再检查冲突、备份配置并在线增加 Peer，保留其他 Peer；目标隧道握手和 Hub 连通性通过后回填 WG IP。

安装当前支持 Debian/Ubuntu apt、systemd、可用 SSH/sudo 及已运行并持久配置的 WireGuard Hub；新隧道只路由所选私有 IPv4 /24 至 /30 网段。存在其他隧道配置时保留并报错；执行中断时配置和地址预约保留，修复网络/依赖后可重复运行。脚本可在作业页面编辑，凭据和私钥不作为运行参数。
