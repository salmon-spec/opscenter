# OpsCenter 5.5.35 · 自动化编辑工作区

automation 0.5.0 将脚本与输入参数放在同一编辑窗口，参数名称、说明、类型、默认值、必填项和可选值均可修改、增删。脚本和参数一起保存 Git 版本；切换文件及关闭窗口时保护未保存内容。运行表单根据保存后的参数定义生成，服务端验证输入与默认值。

执行概览可进入对应历史；历史支持模板、状态和时间范围筛选。日志窗口支持搜索、跟随输出、复制及通过工作台现有下载通道导出文本。沿用现有模板、任务与计划。

界面交互参考 [Semaphore](https://github.com/semaphoreui/semaphore)、[AWX](https://github.com/ansible/awx) 和 [Rundeck](https://github.com/rundeck/rundeck)。
