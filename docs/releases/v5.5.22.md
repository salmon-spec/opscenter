# OpsCenter 5.5.22

2026-10-25 发布后审查修复。

- 文件上传先完整写入独占临时文件，再使用不覆盖目标的发布操作；同名竞争返回 409，传输失败清理临时文件。
- UFW 启用前校验 SSH 放行规则；K3s/PVE 主机拒绝直接启用。普通主机需先建立宿主定时回退，并在新 SSH 连接和状态核验通过后取消回退。无法确认复杂规则、firewalld 离线规则或回退能力时，需从主机控制台执行独立网络变更。
- 历史指标清理保持 14 天保留策略，改为 1000 行小批次与物理行定位，减少二次主键索引查找；保留 SQL 错误传播、锁/语句超时和总运行预算。

安全回归覆盖上传竞争/中断、SSH 来源网段、拒绝/未知规则、受管节点、回退计时器和新连接失败。真实规模恢复和生产清理结果见当次验收记录；微型数据库测试不能代替生产吞吐验收。

回滚应用镜像与 CronJob 配置不会恢复已按保留策略删除的历史行。指标表变更前需验证独立保护副本，并保留原应用镜像、部署模板和 CronJob。
