# v5.5.28 · 生活模块

新增订阅与续费、家庭物品、生活待办三个原生工作台入口，分别通过独立API适配器对接Wallos、Homebox和Vikunja。包括订阅周期费用与CSV预览导入、物品保修/凭证/维护、生活清单/标签/重复任务、到期聚合及持久化提醒队列。

写入使用幂等标识，结果未知时保留待核对状态；附件与内部接口均鉴权，上游凭据保留服务端。默认仅站内提醒，用户配置Webhook后可启用外部投递。首版本人使用，家庭成员独立身份尚未提供。

三模块在独立命名空间运行，上游固定digest、单副本PVC；工作台网关通过同源路径访问适配器。构建和检查纳入已有CI，部署配置与运行约定见[生活模块](../../modules/life_common/README.md)。发布状态以生产验收记录为准。
