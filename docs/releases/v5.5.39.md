# 5.5.39 并行候选记录

以下两组改动分别基于 5.5.38 开发。统一集成候选见 [5.5.40](v5.5.40.md)。

# 5.5.39：响应性能优化候选

2026-11-05；基于 5.5.38 / 7a6dfdaf。本版本尚未部署生产。

- 主机列表的服务计数改为一次分组查询，避免每台主机分别 count；服务列表的主机信息改为一次批量读取。接口字段与数据含义保持兼容。
- 多个页面同时刷新大屏时，只允许一次重建聚合结果，其余请求复用同次刷新。5 秒缓存时效、非数据库数据刷新、ETag/304 与错误重试保持原契约；热缓存请求不等待重建锁。
- 服务广场按路由加载，首页无需加载该页面代码。
- 打开终端时不再提前读取文件目录；第一次点击文件传输时初始化，再切换页签保留已加载目录。

增加数据库查询次数、响应内容与并发刷新回归；运行前端检查和构建，并通过本地模拟 API 的浏览器验证按需加载及文件页签行为。生产耗时与真实 PostgreSQL 并发仍需发布验收确认。没有数据库结构变更、依赖增减或生产配置修改。


# OpsCenter 5.5.39

监控大屏内置编辑入口和样式模板，旧 /screen/manage 地址兼容跳转；侧栏统一使用“监控大屏”。

提供8套主题、4种面板风格、3种组件展示方式及组件独立强调色；新增运维、业务、生活能源、全模块场景模板。原有配置默认使用经典面板和详细展示。

新增13类业务摘要：日志、服务目录、自动化、模型用量、OSS、OpenCode、电费、短信、密码库状态、订阅、物品保修、生活待办、模块运行概览。使用现有鉴权读取接口，同一画布同类组件共享请求，每60秒读取；保留请求失败、未配置与过期提示。密码库只展示服务状态。

扩展既有JSON配置，无数据库结构迁移。保存、发布、并发保护和历史快照继续沿用原流程。新样式字段由5.5.39后端接受，因此后端和前端一起发布；旧版本无法编辑带新字段的草稿，回退部署后应保留数据并升级至兼容后端后继续编辑。

现有电费模块摘要接入大屏；自定义外部数据源管理仍属于后续工作。
