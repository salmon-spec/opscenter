# OpsCenter 5.5.38 — 大屏管理第一阶段

状态：本地开发与隔离验收完成，尚未部署生产。

监控大屏新增 `/screen/manage` 管理入口。支持新建、复制、重命名、删除、保存模板；使用 GridStack 12.4.2 拖拽及缩放组件，也可通过数值精确调整位置和尺寸。提供石墨灰、深海蓝、明亮三个主题，以及背景、面板、文字、强调色、字号和圆角配置。

组件复用现有主机、K3s 和告警数据流，包含状态总览、主机资源、K3s 集群、告警队列、监控图表组和文字说明。图表组保留现有四类图表。组件支持增加、移除、复制及标题编辑。数据刷新、过期标记、失败保留、页面隐藏暂停继续使用现有实现。首期支持每屏最多30个组件，12列网格；小屏自动单列展示，保留桌面布局。

服务端使用现有 SQLAlchemy 数据库保存配置，新增 `screen_boards`、`screen_publications`、`screen_default` 三张表，由现有启动建表流程创建。所有新接口要求已配置的运维身份认证。草稿保存采用 revision 比较更新，过时请求返回409；发布保存不可变快照。设置默认要求已有发布版本，默认大屏不能直接删除。恢复历史版本先更新草稿，再由用户预览和发布；历史快照继续保留。监控大屏读取已发布配置，刷新或重新进入页面时读取最新默认版本。

使用流程：进入“大屏管理” → 新建或复制系统模板 → 编辑布局及主题 → 保存草稿 → 预览 → 发布 → 返回列表设为默认。回退界面版本：选择大屏“版本” → 恢复到草稿 → 预览 → 发布。编辑未保存时离开页面会提示。

本地验收：13项新增后端测试通过；包含鉴权及旧大屏接口的定向回归合计46项通过；全部前端 Node 检查36项通过；Vite生产构建通过。浏览器使用本机独立SQLite数据库、模拟监控来源，验证新建、主题、文字、组件复制/移除、拖拽、缩放、保存、预览、发布、默认切换、刷新、第二浏览器会话、窄屏、草稿隔离和历史恢复后重发。浏览器未出现页面脚本异常。

浏览器验收入口：`backend/tests/screen_boards_preview.py`（启动时强制要求专用 screen-preview SQLite 路径），`frontend-vite/tests/screen-boards.browser.cjs`。截图和结果保存到工作区 `artifacts/screen-management-20261103/`。这组证据不代表生产接入或生产 PostgreSQL 验收。
