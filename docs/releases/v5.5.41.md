# 前端 5.5.41：监控大屏编辑器整改

编辑器统一使用浅色操作界面，与独立配色的监控画布分离。返回入口改为有明确边框、背景、悬停和禁用状态的标准按钮；统一卡片、表单、页签、提示、预览和版本弹窗，增加组件分类、搜索和独立主题页签。

组件使用独立六点手柄拖动，缩放手柄始终可见；拖动或缩放时同步选中组件。保存完成后显示成功提示，编辑器内可直接将已发布版本设为默认。页内确认框支持继续编辑、放弃修改、历史恢复和删除确认；草稿与不可变发布快照机制保留。

业务强调色根据面板背景调整文字明度，保留原强调色作装饰。窄屏隐藏侧栏文字、保留导航名称，按钮和属性表单纵向排布。预览隐藏编辑入口。

后端保持5.5.40，不改变数据库表结构或API配置字段。本次仅滚动更新web，保留现有网关挂载、门户/Codex模块和旧前端资源，回退恢复原web模板，保留业务数据。
