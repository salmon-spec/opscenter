# OpsCenter 5.5.21

2026-10-25 第二轮审查修复候选。生产状态以本轮实际发布清单和对外验收记录为准。

- 文件编辑读写携带 SHA256，提交前核对实际内容，阻止秒级 mtime 与大小不变的冲突；失败保留原文件。SFTP 协议缺少原子 compare-and-swap，不能替代任意外部写入者之间的严格协作锁。
- Agent 健康、端口健康、网络汇总与指标采集统一使用有效资产清单，停止探测/推送退役主机；资产源不可用时保留原降级行为，显式禁用对象始终不采集。
- UFW 解析区分 IPv4/IPv6 与备注，删除保留真实地址族，并核验页面提交的规则身份；不使用过期编号直接删除。
- 历史保留作业显式传播 SQL 错误，验证删除计数，设置 60 秒语句与 5 秒锁超时；保留既定 14 天政策、20000 行批次与预算，调度对齐既有生产每日 UTC 03:20。SQL 失败不再打印完成并退出成功。
- CI 执行脚本与目标源码逐字节核验，打印全部测试组结果，生成完整镜像 ID 清单；包括全部独立模块、OpenCode gateway/runner 和 automation。默认 Caddy 配置同步已验证的生产模块网关，完整镜像不再依赖旧模板补路由。

新增回归覆盖文件同秒同大小冲突、IPv6/备注规则、退役对象及真实保留脚本的错误处理。Windows 缺少 POSIX shell 时脚本用例跳过；Linux 门禁必须实际执行。线上 CI 安装、完整镜像产物、部署与恢复验证记录在项目运维证据中；仅提交源码不能视为已完成生产验收。
