# OpsCenter 5.5.26 — 工作台内密码库

密码管理模块0.2.0在工作台内容区运行完整Vaultwarden网页客户端，支持原密码库账号登录、解锁、密码条目与文件夹管理。顶部提供密码库刷新，客户端地址和CA证书信息收纳在折叠区域。

工作台使用 `https://10.66.66.13/v3/#/extensions/password-manager`，密码库位于独立来源 `https://10.66.66.13:8443`。浏览器需信任家庭服务CA。HTTP工作台页面提供进入HTTPS工作台的同页操作；密码库仅在安全上下文及配置的工作台来源下初始化。

内嵌使用独立来源iframe，保留脚本、表单、下载、对话框和密码库自身存储权限；浏览器同源策略隔离工作台与密码库数据。工作台凭据不传入密码库。Vaultwarden的 `ALLOWED_IFRAME_ANCESTORS` 仅增加 `https://10.66.66.13`；后端状态探测验证密码库CSP中精确的工作台来源。

配置 `VAULTWARDEN_WORKBENCH_ORIGIN=https://10.66.66.13`，沿用已有 `VAULTWARDEN_URL` 和 `VAULTWARDEN_CA_FILE`。部署补丁位于 `deploy/k8s/opscenter-password-manager.patch.yaml`。

新增精确嵌入授权、工作台来源校验、安全上下文、iframe运行和刷新失效回收测试。真实账号主密码由用户在内嵌密码库中输入，客户端验收状态以生产操作记录为准。
